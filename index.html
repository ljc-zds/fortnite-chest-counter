How to use this counter

Click +1 after an opening. Space adds one and Enter subtracts one when focus is outside controls. Shortcuts only work while this page is focused; they do not run inside Fortnite.

Choose a clear starting point. Undo reverses your latest count change. Export creates a readable JSON backup; this version has no import function. The record stays in this browser, so keep one editing tab open and export before clearing site data or switching devices.

Inspect the source

This is an independent, MIT-licensed browser counter with no packages, accounts, trackers or background network requests. It does not connect to Epic, detect opened chests, locate tokens or automate gameplay.

Source code and download instructions on GitHub
